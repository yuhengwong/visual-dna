# Reference analysis

## Inventory and synthesis

For every image record ID, file/attachment, intended role (primary style / supporting style / identity / anti-reference), visible subject, medium, view, crop and evidence limitations. If the user provides many images, inspect all or explicitly state which remain uninspected; do not claim an entire collection was analyzed from a sample. Avoid a fixed upload count limit.

Group images by shared visual grammar before merging. Duplicates and crops of the same artwork are not independent support. User-designated primary references take priority. Otherwise propose a coherent primary cluster and label that choice provisional; ask if incompatible clusters would produce materially different results. Secondary references can contribute named dimensions only. Do not average flat vector, painterly and glossy 3D into an accidental hybrid.

Use a comparison matrix: rows = rule dimensions; columns = references; cells = observation, unknown or exception. Distinguish shared invariants from local motifs and pose-dependent changes. For one reference, flag unobserved angles, expressions and scale behavior as untested. With multiple references report agreement and exceptions instead of a fictitious statistical certainty.

## Measure what matters

Define the measurement frame before giving ratios:

- Character height H: visible top to ground contact, excluding detachable props; note whether ears are included. Body height B: neck/torso start to feet. Never interchange head/H and head/B.
- Head bounding box W × h, with face coordinates x/W and y/h from its upper-left. Define whether ears, hair and outlines are included.
- Eye width/W, eye center spacing/W, eye center y/h, mouth width/W, mouth center y/h. Record ear, muzzle, cheek and limb proportions where visible.
- Normalize outline width to head width or intended output size. Record end caps, joins, contour continuity, interior/outer line relationship and intentional wobble.

Ratios inferred visually are approximate ranges. Do not provide exact pixel measurements without measurement, or derive front-view geometry from a heavily rotated/occluded face. Distinguish perspective, pose, squash/stretch and identity drift. Confidence is high/medium/low with a reason, not a numerical probability. Label tolerances as either observed ranges or proposed production targets.

## Required dimensions

1. Shape / silhouette: primitive families, curvature, corners, symmetry, negative space, detail density and balance.
2. Geometry / face: head/body grammar and facial layout using the frames above; what remains invariant versus expressive.
3. Color: palette roles, value and saturation relationships, approximate HEX only when supported, area distribution, background contrast and forbidden colors. Separate sampled color from perceptual estimate; profiles and lighting affect appearance.
4. Line: weight system, color, caps/joins, contour versus detail, no-line boundaries where relevant.
5. Rendering: flat/volume, shadow count and edges, light direction, gradients, highlights, material, texture size/density and where texture is absent. Do not call raster artwork vector or a model sheet 3D geometry.
6. Composition: framing, margin, viewing angle, camera feel, background and visual hierarchy; distinguish presentation from inherent style.
7. Commercial adaptation: readability at intended sizes, monochrome behavior, embroidery/print limits only when relevant. Suggest tests rather than claim manufacturability.

## Style versus identity

Reusable rules may include rounded geometry, low face placement, restrained palette and uniform dark outlines. Specific ear silhouette + unique facial marking + signature scarf + their arrangement may identify a character even if each element is common. In original-design mode, explicitly redesign that combination: choose a distinct silhouette, facial arrangement/markings and signature cue. Cosmetic recoloring alone does not demonstrate a distinct character.

For a same-character continuation, use the supplied identity as a separate lock. For a style family of different characters, preserve style rules while giving each identity its own silhouette and cues. Ask whether references are style-only or an intended existing identity if this is ambiguous and consequential. Do not refuse routine style analysis or request rights documents by default.
